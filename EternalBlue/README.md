# MS17-010 (EternalBlue) — Practical Security Lab

## Overview

A hands-on investigation of the MS17-010 vulnerability,
exploring reconnaissance, vulnerability identification,
controlled exploitation, post-exploitation analysis,
and remediation.

This lab extends beyond the guided TryHackMe exercise
through an independently configured Windows 7 virtual
machine in an isolated environment.

## Lab Environment

| Component | Details |
|---|---|
| Attacker Machine | Kali Linux |
| Target Machine | Windows 7 |
| Exploitation Framework | Metasploit |
| Traffic Analysis | Wireshark |
| Guided Platform | TryHackMe |

## Methodology

1. Lab environment configuration
2. Reconnaissance and scanning
3. Vulnerability identification
4. Controlled exploitation
5. Post-exploitation investigation
6. Network traffic analysis
7. Vulnerability remediation
8. Security validation

## Key Security Findings

- Risks associated with SMBv1.
- Impact of the MS17-010 vulnerability.
- Importance of security patching.
- Network-level detection opportunities.
- Defensive hardening practices.
